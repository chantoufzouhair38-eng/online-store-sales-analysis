# Online Store Sales Analysis with Pandas

## Project Overview
This project analyses an online store sales dataset using Python and Pandas. The objective is to extract useful business insights, understand sales performance, and practise professional data analysis techniques.

## Objectives
- Calculate total revenue and sales performance.
- Analyse revenue by product, city, and month.
- Identify the best-performing products and cities.
- Analyse customer orders and ratings.
- Reshape datasets using Pivot Tables and Melt.
- Apply advanced Pandas techniques.

## Tools and Technologies
- Python
- Pandas

## Pandas Techniques Used
- DataFrame creation and exploration
- GroupBy and aggregation
- Pivot Tables and Melt
- Transform and Rank
- Qcut
- Merge
- CSV export

## Business Questions
1. Which product generated the highest revenue?
2. Which city generated the highest revenue?
3. Which month had the highest revenue?
4. Which customer placed the most orders?
5. What was the average customer rating?
6. Which payment method generated the most revenue?

## Project Results
The analysis produces business summaries and CSV reports that can support sales-performance decisions.

## How to Run
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Open `notebooks/sales_analysis.ipynb`.
4. Run the notebook cells.
